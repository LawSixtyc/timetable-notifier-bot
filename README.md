Студенты и преподаватели тратят время на повторный поиск расписания и часто узнают об изменениях слишком поздно.
Официальный источник расписания не предоставляет удобного способа отслеживать обновления для выбранных групп/преподавателей/аудиторий.
Из-за этого пользователи вынуждены регулярно проверять расписание вручную и рискуют пропустить важные изменения.
